# 마감의 숲 — 공동 작업실 개발 인수인계

최종 갱신: 2026-10-27
상태: 현재 저장소 `main`의 직접 확인 결과 + 대화상 보고를 구분하여 기록

## 확인된 저장소 상태
- 저장소: `jadam60177/The-Forest-of-a-Writer` (기본 브랜치 `main`).
- `index.html` 안의 작업실 푯말 버튼은 현재 `title="작업실은 아직 준비 중이에요"`로 표기되어 있음.
- `index.html`에서 공동 작업실의 착석/옷장 모듈 코드는 확인되지 않았음.
- 이 문서에서 다루는 '공동 작업실'은 디스코드 음성채널의 코인 적립 작업실과 다른 신규 화면임.
- 최근 착석·옷장 개발 소스는 현재 저장소 기본 브랜치에서 미확인. 별도 시제품이나 ZIP으로 관리 중일 수 있음. **코드 존재 여부는 확인 전 추정하지 말 것.**

## 사용자와 합의된 기능 (대화 기록, 코드 검증 전)
- 아바타: 2.5등신, 공식 서기/앉기 몸체 PNG 두 장 고정.
- 파츠: 앞머리/뒷머리, 얼굴, 옷, 염색 마스크. 원본 마스터 몸체 수정 금지.
- 착석: 전면을 바라보는 책상 5자리 (상단 3 / 하단 2, 가운데 빈 자리), 기존 구현 유지.
- 5명 초과 시 매시 정각 좌석 교체.
- 디스코드 작업 채널 접속 인원 표시; 작업 흐름을 방해하는 타이머 없음.
- 배경: 1레벨은 최소 장식, 업그레이드로 장식 추가. 낮/밤 버전 예정.
- 장기 재사용: 아바타를 축소해 별도 《마감의 산》 프로젝트에 사용할 계획.

## 미검증 버그
- 옷장 신규 에셋 장착 시 머리카락 레이어/위치가 깨져 보인다는 보고.
- 원본 시트의 모습은 정상이고 프리뷰에서도 동일한 오류가 재현된다고 보고됨.
- 에셋 자체를 변경하기 전 렌더링 좌표/파츠 앵커/크롭 규칙/서기·앉기 기준 혼용 여부 확인 필요.
